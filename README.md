# POPTRIS

A small browser Tetris clone, built as a class demo. Pure HTML, CSS, and JavaScript with no build step or dependencies.

**Play it:** https://margmarg.github.io/poptris/

## Controls

| Key | Action |
| --- | --- |
| ← → | Move |
| ↑ | Rotate |
| ↓ | Soft drop |
| Space | Hard drop |
| P | Pause |
| M | Mute |

## Running locally

Open `index.html` in a browser. That is all it needs.

## Files

- `index.html` — page layout and canvas
- `game.js` — game logic
- `styles.css` — styling
